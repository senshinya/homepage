# 404 底纹固定位置设计

- 日期：2026-07-30
- 状态：方案已确认

## 背景

404 页面的大号 `404` 底纹与正文共用 `.stage` 的同一条 Grid 轨道。旧文章卡片与推荐列表异步出现时，正文高度增加；`align-content: center` 随之重新计算轨道起点，因此没有动画属性的底纹也会被布局带着移动。

## 设计方案

- 保留正文现有的卡片切换、地址展开与推荐列表展开动画。
- 将 `.stage-mark` 从 Grid 尺寸计算中移出，改为相对 `.stage` 绝对定位。
- `.stage` 作为定位容器；底纹保持水平居中，并以舞台垂直中点为稳定锚点，维持当前首屏中数字位于正文后方偏上的构图。
- 底纹只与错误页舞台一起滚动，不使用相对视口的 `position: fixed`。
- 不修改 404 文案、字号、颜色、描边、响应式断点或正文布局。

## 验收

- 源码回归测试确认 `.stage` 建立定位上下文，`.stage-mark` 使用绝对定位与稳定的舞台锚点。
- 回归测试确认 `.stage-mark` 不再使用依赖 Grid 轨道起点的 `place-self`。
- 现有测试、ESLint、Stylelint 与生产构建通过。
- 在桌面宽度与 375px 宽度下打开旧文章 404 页面，确认正文动画期间数字不再位移，页面滚动时数字仍随错误页自然离开视口。
