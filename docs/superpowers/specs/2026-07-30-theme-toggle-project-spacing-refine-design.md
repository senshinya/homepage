# 主题切换与项目排布微调设计

- 日期：2026-07-30
- 状态：范围已口头确认，待书面复核

## 背景

本轮只修正两个视觉回归，不改变当前主页已经确认的整体风格：

1. 主题切换按钮因新增 `min-width: 40px` 与 `min-height: 40px`，可见高度明显高于改动前。
2. 项目列表桌面端使用顶部对齐，图片与内容之间的间距偏紧，中线也未对齐。

## 设计方案

### 主题切换

- 从 `ThemeToggle.vue` 的按钮样式中移除 `min-width` 和 `min-height`，恢复改动前由内容与内边距自然决定的尺寸。
- 保留本轮已经加入的无障碍与交互改进：`role="group"`、`aria-pressed`、`type="button"`、明确的颜色过渡、悬停能力判断与选中态。
- 不改图标、边框、圆角、颜色、按钮间距和切换逻辑。

### 项目排布

- 桌面端将图片与内容的列间距改为 `clamp(2rem, 5vw, 4rem)`，即随视口在 2–4rem 之间平滑变化。
- 桌面端将两列从顶部对齐改为纵向居中：`align-items: center`。
- 移动端继续使用单列结构与 `1rem` 间距，不扩大手机端的纵向留白。
- 不改列宽比例、奇偶项目的左右交替、图片尺寸、文案、字体、动效或断点。

## 非目标

- 不重新设计主题切换组件。
- 不调整页面其他区域的间距、色彩或动效。
- 不重构项目数据与组件结构。

## 验收

- 源码回归测试确认主题按钮不再声明 `min-width` / `min-height`。
- 源码回归测试确认项目桌面端使用 `align-items: center` 和 `clamp(2rem, 5vw, 4rem)`，移动端仍为 `1rem`。
- 运行现有测试、ESLint、Stylelint 与构建检查。
- 因当前环境没有可用的浏览器运行时，代码检查通过后保留局域网开发服务，请用户分别在桌面宽度与 375px 宽度下做最终视觉确认。
